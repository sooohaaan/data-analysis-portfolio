## 2. 초기 로드맵 — 5단계 원안

로드맵 docx가 정의한 **[설계 → 수집 → 적재 → 분석 → 기획 연계]** 5단계 원안 요지입니다. (실제 진행은 [README 진행 현황](../README.md#-프로젝트-진행-프로세스-계획--5-phase--진행-현황) 참조)

| Phase | 원안 요지 | 실제 변경 |
|-------|----------|----------|
| **1. 인프라·스키마** | 클라우드 DB(Supabase) 생성 · ERD 6개 테이블 설계 · DDL | → 최종 **9개 테이블**(superapp_reviews·reference_stats 추가) |
| **2. 수집 파이프라인** | 앱스토어·유튜브·SNS·블로그 수집 + DB 자동 적재 | → SNS **보류**(Meta ToS), 뉴스·하드웨어·슈퍼앱 **추가** |
| **3. 다국어 전처리** | 언어 감지 → **Google Translate 전체 번역** → 영어 기반 분석 | → **XLM-RoBERTa 다국어 직접 처리**(전체 번역 폐기, 12시간→2시간) |
| **4. SQL 분석** | 하위 별점 집중 분석 · 통계/트렌드 · 감성 분석 | → Supabase timeout으로 **Python DataFrame** 전환 · VOC **2계층 재분류** |
| **5. 기획 연계** | 데이터 기반 PRD·기능 명세 · 포트폴리오 스토리텔링 | → PRD + 시장조사 + 요금정책 + 설계 산출물 + 발표덱 57장 |

## 4. 계획 대비 주요 변경 (원안 → 실제)

> 계획은 데이터로 검증되며 계속 수정됐습니다. 상세 이력 → [README 회고](../README.md#-프로젝트-진행-기록--문제--시도--결과-발표-회고용)

| 항목 | 원안 | 실제 | 사유 |
|------|------|------|------|
| 분석 앱 | 3개(LOCA·Green SM·V-Green) | **5개**(+태국 3사) | LOCA 리뷰 7건·V-Green=Green SM 동일 ID |
| 번역 전략 | Google Translate 전체 번역 | **XLM-RoBERTa 직접** | 12시간 병목 |
| 수집 소스 | 앱·유튜브·SNS·블로그 | + **뉴스·HW·슈퍼앱**, SNS 보류 | 시장·정책·HW·경쟁 근거 |
| 테이블 | 6개 | **9개** | superapp_reviews·reference_stats |
| 분석 차트 | (원안 미명시) | **20개** | 앱9+HW7+연계1+2계층·SoV 3 |

> ⚠️ **폐기된 원안 수치**: WBS·로드맵에 적힌 "앱오류 58.6%/35%", "결제오류 16.8%", "차트 17개", "news 733/2,060" 등은 *초기/중간 수치*입니다. **VOC 2계층 재분류** 이후 충전앱 #1 불만은 **앱 불안정 27.6%**로 규명됐고, 뉴스는 **3,085건**(DB 실측)으로 정정됐습니다. 현재 정본 → [README](../README.md) · [DRD](data_requirements.md).

## 6. 방법론 매핑 — CRISP-DM × SDLC

이 계획(Phase 0~5)은 데이터 분석 표준 방법론 **CRISP-DM**(*Cross-Industry Standard Process for Data Mining*)으로 수행됐고, 그 산출물은 서비스 **SDLC**의 상류(계획→분석→설계) 단계에 해당합니다.

| 프로젝트 Phase | CRISP-DM | SDLC(서비스 관점) |
|---|---|---|
| Phase 0 계획 | 비즈니스 이해 | 계획 |
| Phase 1~2 인프라·수집 | 데이터 이해 | (분석 인프라) |
| Phase 3 전처리 | 데이터 준비 | 분석 |
| Phase 4 분석·분류 | 모델링·평가 | 분석 |
| Phase 5 기획 연계 | 배포 | 분석(PRD)·설계 |

> 🔁 CRISP-DM은 순환 모델이며, **VOC 2계층 재분류**가 *평가 → 데이터 이해 회귀* 루프에 해당합니다("앱오류=OCPP" 가설 기각 → 앱 불안정 27.6% 규명). 상세 → [README 방법론](../README.md#-방법론--crisp-dm수행--sdlc포지셔닝).
